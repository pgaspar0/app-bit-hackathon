1. Resumo Executivo

O App BiT é uma plataforma B2G (Business to Government) de apoio à decisão para gestores públicos. Consolida dados do dataset Vísent CDRView (concentração de pessoas e cobertura de rede por região) com fontes públicas, permitindo consultas em linguagem natural sobre 5 serviços críticos:

  • Formações — Programas de formação tech por região
  • Empregabilidade — Taxa de emprego formal vs concentração
  • Experiências Estruturantes — Iniciativas sociais e culturais
  • Mentorias — Programas de mentoria pública
  • Saúde Mental — Indicadores de saúde mental vs conectividade

O frontend está construído em React + Tailwind CSS com mapa interactivo Leaflet. Nesta fase (Semana 1), todos os dados são mockados para demonstrar o fluxo completo.

4.2. SidebarConsulta (src/components/SidebarConsulta.jsx)

Função: Coluna lateral de consulta. Permite ao gestor selecionar região, fazer perguntas em linguagem natural e visualizar respostas mockadas.

Estados internos:

EstadoFunção

Mock data por serviço:

Cada um dos 5 serviços tem:

  • 3 sugestões de perguntas (traduzidas em PT/ES/EN)
  • 1 resposta_ia com análise em linguagem natural
  • 2 dados no formato {regiao, valor, fonte}
  • Fontes associadas

Exemplo (formacoes):

    { regiao: "Distrito Industrial Sul", valor: 72, fonte: "Vísent CDRView" }

}

Estados visuais:

  • Aguardando consulta: dashed border com "?" e texto explicativo
  • Loading: spinner animado com a cor do serviço ativo
  • Resultado: bloco de resposta + grid de cards + badges de fontes + botão "Nova Consulta"

6. Internacionalização (PT/ES/EN)

O sistema suporta 3 idiomas: Português, Espanhol e Inglês.

Mecanismo:

  • Estado idioma no DashboardLayout (valor padrão: 'pt')
  • Passado como prop para SidebarConsulta e MapaInterativo
  • Função t(obj, idioma) que retorna a string no idioma correto: 
    function t(obj, idioma) {
  return typeof obj === 'string' ? obj : obj[idioma];
}
  • Selector de idioma no header (PT | ES | EN) — toggle visual com bg branco no ativo

Textos traduzidos:

  • Nomes dos 5 serviços
  • Sugestões de perguntas (3 por serviço × 3 idiomas = 45 frases)
  • Respostas da IA (5 serviços × 3 idiomas = 15 blocos de texto)
  • Nomes das regiões
  • UI genérica: placeholders, botões, legendas, tooltips, labels
  • Legenda do mapa e status de alerta
  • Badge do dataset
  • Nome do dashboard
Como adicionar um novo idioma: Acrescentar a chave nos objetos de tradução (ex: fr: '...'), adicionar o botão no seletor e o caso no idioma ===.

7. Estratégia Responsiva

O layout adapta-se a 3 breakpoints usando classes utilitárias do Tailwind:

BreakpointLarguraComportamento
Mobile< 640pxStack vertical: header empilhado, sidebar em cima, mapa em baixo. Input + botão empilhados. Badge reduzido para "CDRView". Scroll horizontal nas tabs.
Tablet640px — 1023pxHeader horizontal. Sidebar + mapa ainda empilhados. Cards em grid de 2 colunas.
Desktop≥ 1024pxSplit view: sidebar 40% à esquerda com scroll, mapa 60% à direita ocupando calc(100vh - 96px). Tabs sem scroll.

Detalhes de implementação:

  • Header: flex-col sm:flex-row — empilha em mobile
  • Main: flex-col lg:flex-row lg:h-[calc(100vh-96px)] — split em desktop com altura total
  • Sidebar: lg:flex lg:flex-col lg:h-full lg:overflow-hidden + lg:flex-1 lg:overflow-y-auto no conteúdo
  • Mapa: lg:flex lg:flex-col lg:h-full + flex-1 no container
  • Tabs: overflow-x-auto + w-max para scroll horizontal em mobile
  • Tooltip do mapa: fixed em mobile (colado ao fundo), absolute em desktop (centrado)
  • Botões: min-h-[44px] para touch targets acessíveis
  • Textos: text-xs sm:text-sm, text-2xl sm:text-3xl, etc.

9. Fluxo do Utilizador

  1. Abrir a app — vê o header, as tabs dos 5 serviços e o split sidebar + mapa
  2. Selecionar serviço — clica numa tab (ex: Formações). O mapa atualiza cores e legendas
  3. Escolher região — dropdown no topo da sidebar (opcional: "Todas as Regiões")
  4. Fazer pergunta — clica numa sugestão OU digita no input
  5. Clicar "Consultar IA" — vê spinner de 1.2s, depois aparece:
    • Bloco com a resposta em linguagem natural
    • 2 cards com valores e barras de progresso
    • Badges com as fontes dos dados
  6. Explorar mapa — clica nos círculos para ver popups com indicadores
  7. Mudar idioma — clica em PT | ES | EN no header. Todo o conteúdo traduz
  8. "Nova Consulta" — limpa o resultado e volta ao estado inicial

12. Notas Técnicas

  • Leaflet CSS: No index.html é carregado via <link> do CDN. No Vite será via import 'leaflet/dist/leaflet.css' no entry point.
  • react-leaflet vs Leaflet puro: O MapaInterativo.jsx (JSX) usa react-leaflet (declarativo). O index.html (CDN) usa Leaflet vanilla com useEffect + useRef (imperativo). Ambos produzem o mesmo resultado.
  • Mock vs Real: Toda a lógica de dados está nos ficheiros SidebarConsulta.jsx e MapaInterativo.jsx. Para ligar ao backend, basta substituir os setTimeout por chamadas fetch aos endpoints.
  • Coordenadas: As regiões usam coordenadas reais de Luanda, Angola (dataset Vísent CDRView).
  • Semântica: O código usa <header>, <main>, <section> para acessibilidade.
  • Sem emojis: Todo o UI é profissional sem ícones gráficos (apenas texto + SVG).
  • Ficheiros na raiz: index.html é standalone. Os componentes React estão em src/components/.
